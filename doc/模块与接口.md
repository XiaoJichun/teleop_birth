# 模块划分与仿真/真机双端口

> 完整架构与算法流程见 [架构与算法流程总览.md](./架构与算法流程总览.md)。

## 包结构（四类）

```
src/teleop_birth/
  ui/          菜单与场景工坊
  scene/       物品、布局、采集、MCAP；plugins/；assets/
  robot/       registry + sim/real 后端 + ee + io + arm/wheeled/biped
  teleop/      schema pipeline mapping control xr ik record config
```

## 双端口（接真机只换实现）

```python
from teleop_birth.robot.io import StateReceiver, ActionPublisher, RobotEndpoint, RobotState, RobotAction

class StateReceiver:   # 状态接收
    def receive(self) -> RobotState: ...

class ActionPublisher: # 动作发布
    def publish(self, action: RobotAction) -> RobotState: ...

class RobotEndpoint:   # 成对封装
    state_port: StateReceiver
    action_port: ActionPublisher
```

- **仿真**：`robot/sim` 实现后，经 `BackendAsEndpoint` → `EndpointBackendAdapter` 接入 `TeleopLoop`。
- **真机**：在 `robot/real/` 新建类，实现同一双端口；Mapper / Loop / XR **不动**。
- **换臂坐标**：只换 `mapper.arm_profile`（或 `frame.arm_profile`）；`FrameMapPort` 对 sim/real 相同，见 `teleop/frame/` + `scene/plugins/frame/`。

`RobotState` / `RobotAction` 为类封装的数据对象；勿在上层直接写关节角。

## TeleopLoop 兼容

当前 Loop 仍消费 `RobotBackend`（`teleop_birth.robot`）。工厂里：

```text
raw backend → BackendAsEndpoint → EndpointBackendAdapter → TeleopLoop
```

新代码请对 `endpoint.state_port` / `endpoint.action_port` 编程。
