# 模块划分与仿真/真机双端口

## 包结构（可单独提取）

```
src/teleop_birth/
  schema/        # 总线类型 XRObservation / SparseTarget
  robot_io/      # ★ 状态接收 + 动作发布（仿真/真机统一口）
  xr/            # XR 源
  mapping/       # Mapper
  control/       # clutch / 滤波 / 轴对齐 / 延迟
  ik/            # DLS / SSIK / cuRobo（与场景解耦）
  ee/            # 末端执行器
  sim/           # MuJoCo 场景拼装（仅资产）
  embodiment/    # 具体机器人实现
    sim/         # MujocoDualUR / Mock
    real/        # G1 stub → 真机 SDK
  pipeline/      # TeleopLoop
  config/        # Hydra factory
  cli/           # 终端
  record/        # 日志
  backend/       # 兼容再导出（旧 import 仍可用）
```

## 双端口（接真机只换实现）

```python
from teleop_birth.robot_io import StateReceiver, ActionPublisher, RobotEndpoint, RobotState, RobotAction

class StateReceiver:   # 状态接收
    def receive(self) -> RobotState: ...

class ActionPublisher: # 动作发布
    def publish(self, action: RobotAction) -> RobotState: ...

class RobotEndpoint:   # 成对封装
    state_port: StateReceiver
    action_port: ActionPublisher
```

- **仿真**：`embodiment/sim/*` 实现后，经 `BackendAsEndpoint` → `EndpointBackendAdapter` 接入 `TeleopLoop`。
- **真机**：在 `embodiment/real/` 新建类，实现同一双端口；Mapper / Loop / XR **不动**。

`RobotState` / `RobotAction` 为类封装的数据对象；勿在上层直接写关节角。

## TeleopLoop 兼容

当前 Loop 仍消费 `RobotBackend`。工厂里：

```text
raw embodiment → BackendAsEndpoint → EndpointBackendAdapter → TeleopLoop
```

新代码请对 `endpoint.state_port` / `endpoint.action_port` 编程。
