# 配置文件指南

本文说明 `configs/` 目录结构、各文件职责，以及「改某个行为该动哪个 YAML」。

更短的 Hydra/设备分层说明见 [configs/README.md](../configs/README.md)。

---

## 目录总览

```
configs/
  config.yaml                 # Hydra 入口（遥操主流程 defaults）
  algorithm/                  # 算法：IK / mapper / runtime（换设备基本不改）
  device/                     # 设备：source / backend / end_effector / paths
  setup/                      # Pico·XRobo 安装用 overrides
  ui/                         # 终端菜单文案与入口
  scene/                      # ★ 场景物品、语义任务、采集录制
    cli.yaml                  # 生成 / 摆放 / 采集的默认参数
    recording.yaml            # MCAP topic + 多相机机位
    props/*.yaml              # 单个道具外观与物理
    tasks/*.yaml              # 语义任务定义（指令、物体、stages）
```

根目录下的 `ik/`、`backend/` 等 symlink 只为 Hydra 短写：`ik=ssik`、`backend=mujoco_dual_ur`。

## 我想改… → 改哪个文件？

| 目标 | 配置文件 | 关键字段 |
|------|----------|----------|
| 采集是否开窗口、观摩速度 | `scene/cli.yaml` → `collect` | `render`, `pace_s` |
| 采集集数 / 任务 / 臂 | `scene/cli.yaml` → `collect` | `episodes`, `task`, `arm`, `seed` |

| **相机机位 / 分辨率 / 采样** | `scene/recording.yaml` → `cameras` | `views`, `width`, `height`, `every_n_steps` |

## 场景采集相关（重点）

### 1. `configs/scene/cli.yaml`

交互菜单「一键：自动化采数据」与 `tools/scripts/scene_ops/03_collect_pick_place.py` 共用。

- `collect.recording` → 指向录制配置（默认 `scene/recording.yaml`）
- `collect.camera.enabled` → 仅总开关；机位与 topic **不要**写在这里
- `collect.hold_steps: 0` → 段与段之间不停顿（流畅抓取）
- `collect.pace_s` → 仅影响观摩快慢，不改变轨迹形状

### 2. `configs/scene/recording.yaml`

录制专用：

- `topics`：Foxglove 打开 MCAP 时看到的话题名，可按项目规范改名
- `cameras.views`：默认三路
  - `third_person`：世界系固定第三人称
  - `wrist_left` / `wrist_right`：挂在 `L_g_pinch` / `R_g_pinch`（与 backend 的 prefix + `tcp_site_suffix` 一致）

默认相机话题：

- `/cam/third_person/compressed`
- `/cam/wrist_left/compressed`
- `/cam/wrist_right/compressed`

### 3. `configs/scene/tasks/*.yaml`

定义「做什么」：中英文指令、涉及物体、pick/place/reset stages。  
采集脚本按 `collect.task` 加载对应文件。

### 4. `configs/scene/props/*.yaml`

定义「桌上有什么」：几何、颜色、质量、默认位姿、语义标签。

## 遥操主流程（Hydra）

入口：`configs/config.yaml` → `run_teleop.py` / 菜单「自定义：遥操配置」。

| 分组 | 目录 | 作用 |
|------|------|------|
| runtime | `algorithm/runtime/` | 控制环频率、时长、日志 |
| ik | `algorithm/ik/` | DLS / SSIK / cuRobo |
| mapper | `algorithm/mapper/` | 相对遥操、clutch、姿态模式 |
| source | `device/source/` | mock / xrobo |
| backend | `device/backend/` | mujoco 仿真 / stub / 真机 |
| end_effector | `device/end_effector/` | gripper / dex_hand |
| paths | `device/paths/` | 资产与输出路径 |

换 Pico 仿真常见组合：

```bash
uv run python run_teleop.py source=xrobo backend=mujoco_dual_ur
```

## 流畅抓取与穿模说明（实现约定）

代码侧约定（一般无需改配置）：

1. **流畅**：`hold_steps=0`，段内 ease-in-out 插值 + 夹爪连续开合，不再在每段末停顿。
2. **视觉一致**：粘性抓取吸附后将方块对齐到 TCP 工具系偏移，并暂时关闭该物体碰撞，避免夹爪「穿过」方块却看起来没夹住。

若仍觉得夹偏：可在代码 `StickyGrasp.grasp_offset_xyz` 微调；机位则改 `recording.yaml`。

## 快速检查清单

采集前：

1. `uv sync --extra collect`
2. 确认 `scene/cli.yaml` 中 `render` / `pace_s` / `task`
3. 确认 `scene/recording.yaml` 三路相机与 topic
4. 运行：`./start.sh` → 一键采数据，或  
   `uv run python tools/scripts/scene_ops/03_collect_pick_place.py`
5. 用 Foxglove 打开 `logs/mcap/*.mcap`，核对三路 `/cam/.../compressed`
