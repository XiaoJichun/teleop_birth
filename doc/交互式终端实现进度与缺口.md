## 0. PyQt 未出现（已修）

**原因**：旧 `start.sh` 未装 PyQt6；`viewer.launch()` 阻塞主线程。

**修复**：PyQt6 主依赖 + `start.sh` 自动补装；MuJoCo `launch_passive` 后台；工坊「刷新 MuJoCo 预览」。

```bash
bash start.sh
```

若报 `Could not load the Qt platform plugin "xcb"` / `xcb-cursor0`：

```bash
sudo apt update && sudo apt install -y \
  libxcb-cursor0 libxcb-xinerama0 libxcb-icccm4 \
  libxcb-image0 libxcb-keysyms1 libxkbcommon-x11-0 \
  libegl1 libgl1 libdbus-1-3
```

`start.sh` 会预检系统库；工坊启动前也会探测 `libxcb-cursor`，避免整进程 abort。

### 中文乱码（已修）

**原因**：系统无 CJK 字体时，PyQt 用 DejaVu 渲染中文 → 乱码/方块。与编码无关。

**修复**：主依赖加入 `mplfonts`（内嵌 SimHei / Noto CJK）；工坊与坐标系窗口启动时 `apply_chinese_fonts()` 注册并设为全局字体。建议同时：

```bash
sudo apt install -y fonts-wqy-microhei fonts-noto-cjk
uv sync   # 确保 mplfonts 已装
bash start.sh
```

## 4. 已知限制（非阻塞）

1. **语义**仍是规则关键词，未接云端 LLM（可后续加，规则作 fallback）。
2. **Artixon parallel** 等 `builtin`/URDF 不能直接 `MjSpec.attach` 到 UR；请选 menagerie MJCF（如 Robotiq）。
3. **刷新预览**会关闭并重建 passive viewer（非原地改 geom）。
4. **官方 G1 MJCF** 未入库时用人形占位几何；接真模型后可替换 `_compile_empty_humanoid`。
5. LeRobot 导出为 **兼容目录 + npy 张量**，未必 100% 对齐官方 HuggingFace 数据集脚本。
